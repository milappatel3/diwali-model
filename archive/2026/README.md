# Diwali Exhibition 2026 — archive

The event layout and lighting plan as used for Diwali 2026 (Assembly Hall · BAPS Milpitas).

- `diwali-exhibition-2026.lightplot.json` — the Plan & light map (exhibition, drapes, fixtures, probes). Load it any time from
  **Venue & settings → Import**, or with **Start from the 2026 layout**.
- `campus-edits-2026.json` — the Campus plan event layer (zones, signs, KDC booths and activities, Utsavpur gate, entrance,
  pick-up lanes, annakut, shoe stands …). Load it from **Campus plan → Import**.
- The full 2026 app (code + defaults) is on the GitHub branch `archive/diwali-2026`, and a read-only copy of the 2026 site is
  published at `/diwali-model/2026/`.
